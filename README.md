# Práctica Responsive Design - JAW_AUDIOVISUAL

Ejercicio práctico enfocado en la construcción de tarjetas perfil utilizando maquetación adaptable (**Responsive Design**), media queries, la propiedad CSS `clip-path` y la metodología **BEM (Block, Element, Modifier)** para estructurar el código de manera modular y limpia.

## 🚀 Tecnologías Aplicadas
- **HTML5** (Semántica y estructuración)
- **CSS3** (Flexbox, variables, media queries y `clip-path`)
- **Metodología BEM**
- **FontAwesome** (Librería de iconos por CDN)
- **GitHub Pages** (Despliegue y visualización online)
